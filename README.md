## 它解决什么问题

做海外客户开发的人，日常散在七八个工具里：Excel 记客户、邮箱翻往来、网页查公司背景、Word 攒开发信、日历追跟进。Prospector 把这条链路收进一个本地桌面应用，让「找到人 → 摸清背景 → 发出第一封 → 跟进到回复」全程在一个窗口内完成，AI 负责耗时的部分，关键动作仍由你确认。

## 核心功能

- **客户库**：联系人 / 公司两级档案，邮箱为唯一键。支持批量导入——把任意格式的名单、邮件签名、表格直接粘进来即可，自动拆名/姓、归一国家与阶段，重复邮箱自动去重。
- **AI 写开发信**：按客户的语言（中/英/西/葡）与背景自动生成开发信、跟进信、回信草稿；回信模式会先读懂对方来信、逐条应答，并把已查到的真实运价写进草稿（不编数字）。草稿可一键存入素材库复用。
- **公司背调**：输入公司名，联网检索公开资料（Exa / Tavily），产出主营品类、进口活跃度、货代契合点与风险提示，附来源链接；一键写入公司档案或建为新客户。
- **批量发信**：多邮箱账号智能轮换（谁发过的客户还由谁发）、发信时间窗、组间与同公司间隔暂停、每日限额、失败熔断与瞬态重试；退信自动识别并可一键标记流失。入队 ≠ 发送——真正外发前你总能在「发送中心」核对。
- **收件箱**：IMAP 拉取并自动分类（询盘 / 回复 / 退信 / 自动回复），自动匹配到对应联系人；退信一键处理，询价邮件自动联动运价查询。
- **CRM 跟进**：管线看板、到期与逾期提醒、跟进时间线、沉默超期标红；「谁该跟进了」不再靠记忆。
- **运价库**：用户登录并授权 Navigator 后，按航线 / 船司 / 柜型 / 目的港实时查询，附带近期舱位动态；查询记录归属该用户。AI 报价与定向运价更新共用授权接口，退出后不沿用旧报价上下文。私有局域网 IP 支持 HTTP，公网使用须配置受信任的 HTTPS，详见 [来源规范](docs/rates-remote-source-spec.md) 与 [双边验收](docs/navigator-user-query-verification.md)。

## AI 助手

对话栏直接问，即可查数据、也能把结论落成业务动作：

- **只读查询**：运价、联系人、收件箱、邮件总结、到期提醒、队列进度、账号健康、公司背调、航线公开市场行情调研（多源检索 → 逐页核实 → 标注可信度 → 出带来源链接的报告）
- **内容生成**：开发信 / 跟进信 / 回信草稿（多语言）
- **写入动作（执行前必弹确认）**：记跟进、加入客户库、写公司档案、入队发送、标记已读 / 已流失。确认卡会列出将改动哪些字段，确认后仍留审计记录
- **跨页联动**：联系人、邮件、运价、发送队列都有「问 AI」入口，带着当前对象直接跳转对话
- **模型可换**：设置 → 模型与端点，多档端点一键切换（保存即生效），带真实连通性测试；海外端点自动检测本地代理

## 隐私与安全

- **数据在本机**：客户、邮件、运价全部落在本地 `data/` 目录，业务数据不出本机（仅与所配置的模型端点与搜索服务通信，且不记录模型内部推理过程）
- **写操作有人把关**：所有会改动数据的动作执行前必须经你确认，并展示将改动的内容；执行后留审计
- **测试模式（dryRun）**：开启后真实外发被拦截并记为模拟发送，收件与库内操作照常——首次使用建议先全量模拟、再只发自己邮箱试几封
- **密钥不入库**：API Key 等敏感配置在本地 `.env`（已 gitignore），不会进入仓库
- **邮件安全**：渲染客户邮件内容前经过消毒处理，防止恶意 HTML 注入

## 技术概览（面向评审）

| 维度 | 选型 |
|---|---|
| 桌面框架 | Electron 37 + TypeScript + electron-vite |
| 界面 | React + Ant Design + Tailwind CSS |
| 数据层 | SQLite（better-sqlite3，WAL 模式）+ Drizzle ORM |
| 邮件 | nodemailer（SMTP 发送）/ imapflow（IMAP 收信） |
| AI 编排 | @openai/agents 工具调用框架，29 个工具按域拆分 |

架构上分为三层并强制隔离：**services**（业务逻辑与数据访问，禁止依赖 Electron）→ **transport**（IPC 路由，只做参数校验与转发）→ **renderer**（界面）。所有可被 AI 触发的写操作统一走「权限分级 + 人工确认 + 审计留痕」三道闸。

质量基线：提交前执行 `npm run typecheck` 与 `npm test`；测试覆盖 XSS 消毒、事务回滚、迁移幂等、审批闸门等专项。实际通过数量以该提交的 CI 或本地执行结果为准；代码库结构说明见下方开发者文档。
