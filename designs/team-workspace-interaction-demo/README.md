# 团队工作区交互原型

打开 `index.html`，或运行本地静态服务器后访问页面。

销售“团队 → 个人工作台”原型：打开 `sales.html`。它不复制管理员的组织树，只用“今天行动 → 客户上下文 → 下一步操作”组织销售工作。

管理员“我的团队”成员私聊：打开 `my-team.html`。左侧按公司 → 管理员/运营组 → 团队 → 成员直接展开层级，不实现团队群聊；点击任意成员后，中间进入与该成员的私聊，右侧保留成员协作详情和最近动态。

## 两个视角

- 组织视角：公司 → 运营组 → 销售组 → 成员，左侧组织树始终可见；点击上级团队先看下级团队卡片，再进入成员表。
- 工作视角：保留同一团队上下文，把成员按负载、回复积压和待分配事项横向比较，右侧持续显示当前成员详情。

## 关键交互

- 左侧树负责层级递进，顶部面包屑负责快速回退。
- 中间区域只展示当前团队范围，不混入个人工作台和其他团队数据。
- 点击成员只在右侧更新上下文，不跳走整个页面。
- “我的团队”中点击左侧成员会切换中间私聊，同时同步右侧成员上下文；点击团队节点只切换当前团队并进入首位成员私聊。
- 空团队、下级团队和成员列表使用同一主工作区，不额外增加重复页面。

## 管理员与销售分层

- 管理员界面：组织总览负责跨团队比较；“我的团队”负责当前团队成员分组、邀请、名册和协作动态。
- 销售界面：今日行动队列、待回复/待跟进/等待对方、客户详情和下一步操作，解决“我现在先做什么、客户推进到哪一步”。
- 超级管理员进入管理员界面；普通销售直接进入销售工作台，不需要先理解组织结构。
