# v0.9.1-alpha.1

本次汇总本地开发改动为 Windows x64 预发布安装包，包含自 v0.5.6-alpha.1 以来的功能和修复。

- 本地全局搜索：邮件、缓存全文、联系人和手动跟进；支持中文与英文检索。
- CRM：阶段历史可追溯，切阶段不重置跟进逾期；预警/逾期阈值统一配置，收发邮件后刷新相关看板。
- 签名补全：仅填空职位、电话与唯一匹配的现有公司，保留人工字段；修复历史引用签名串入与常见格式漏识别。
- AI 服务商支持 Responses 接口与 Luna 模板；错误端点返回 HTML 或空正文时明确报告失败。
- 运价查询保留局域网接口适配，详情避开程序标题栏；恢复原查询布局。
- 中断的发信批次等待确认后恢复；内联图片不读取本机绝对路径。

验证：708 项测试通过、28 项跳过；类型检查、架构检查与桌面构建通过。包内 Electron/SQLite 隔离验证覆盖迁移、搜索、阶段与签名回填保护。固定 20 封真实邮件复测消除两处历史引用串入，12 个字段输出均正确。

限制：这是预发布版本。签名职位/公司/电话正确提取分别为 4/5、5/16、3/12，仍会漏识别；图片签名、歧义公司和多号码不自动猜测。未执行正式联系人批量回填、真实 SMTP 外发或真实邮箱端到端验收。

构建记录：`npm run pack -- --publish never` 的桌面构建通过，但 builder 的工具缓存解压受 Windows 符号链接权限限制。随后以 `npx electron-builder --win --publish never --config.win.signAndEditExecutable=false` 完成无签名打包；应用版本已从包内 package.json 核对，图标钩子仍执行，builder 的主 EXE 版本资源编辑跳过。

安装包不含本机邮件正文、数据库、密钥或运行配置。复测与修复前检查点保存在本机 `D:/Agent Basement/checkpoints/`，真实样本不进入仓库或 Release。
