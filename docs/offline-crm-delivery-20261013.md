# 客户中心离线交付 · 2026-10-13

用户授权：实施已确认的离线方案，并取消多表导入。工作区版本 0.32.0-alpha.1，未发布；未外发邮件、未写真实客户、未修改中心数据库结构。

## 已实现

- 已登录且具有有效离线授权的账号，可断网进入客户页，查看最近缓存客户、联系人、动态；签名授权最长72小时，首次使用需要联网授权与加载数据。
- 新建/编辑客户及联系人、跟进、单表 CSV/XLSX/粘贴导入先提交本地投影+outbox，再自动提交中心；本地成功与中心同步状态分开显示。原始导入行保留，已有单表映射与预览交互沿用。
- 同账号串行本地事务，中心+用户分库；重启恢复队列。固定发送请求支持丢响应后原键重试。客户/联系人中心 ID 映射及前序写入版本支持离线连续编辑与跟进。
- 中心版本冲突不覆盖本地；同步详情展示两边资料、失败回执，确认后可保留中心或重试本地。保留中心会撤销相关实体全部未同步后续操作。截断成功回执冻结待核查，可按原请求重试。
- 完整分页后台刷新授权范围，中心已有客户按版本更新，成功快照时间与失败/未完成区别显示。身份切换和失效使在途响应无效；权限变化清缓存并冻结队列。
- 已取消多表入口；旧桌面工作簿 IPC 返回停用提示，服务端历史数据和接口兼容保留。

## 保留边界

- 领取、分配、发布、任务/商机修改和关联商机的跟进仍需联网；任务/商机只保证已加载内容的离线读取。不能承诺未缓存附件、邮件或从未同步的客户能离线出现。
- 旧 contacts、邮件、Agent和营销链路仍沿旧账号绑定，本节点未自动迁移匿名库或把中心联系人覆盖进旧 contacts。后续需要评审旧数据归属、中心联系人关联和工具调用方迁移。
- 一条JSON工作集的事务存储优先保证一致性，尚未完成大数据量性能认证。真实用户历史库、真实导入文件和打包安装版升级尚未端到端验收。
