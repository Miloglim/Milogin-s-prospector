# 无边框窗口专项修复（2026-10-19）

## 改动

保留 Electron `frame: false` 和现有自定义标题栏视觉，只统一渲染壳层边界：

- `AppLayout` 增加明确的应用壳层、标题栏、窗口控制区和内容区结构类；
- 标题栏固定高度并禁止被内容区挤压；
- 拖拽区与窗口控制按钮区明确分离，按钮继续使用 `no-drag`；
- 内容区设置 `min-height: 0`、`overflow: hidden`，滚动由原有页面容器负责；
- 详情抽屉沿用现有标题栏避让规则，不增加新的用户提示或页面。

## 原因与提升

原实现把标题栏尺寸、内容区 flex 约束和页面抽屉避让分散在多个位置，容易出现详情被标题栏盖住、窗口缩放时内容溢出、拖拽区吞掉按钮点击的问题。现在窗口壳层只负责几何边界，页面继续负责自己的滚动和业务交互。

## 副作用

主窗口顶部仍保留 36px 自定义标题栏；页面内容可用高度会明确扣除这一行。没有新增 IPC/API、数据库、依赖或配置；系统边框仍然不显示。
