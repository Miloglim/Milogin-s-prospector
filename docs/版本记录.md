# 版本记录

## 0.8.0-alpha.1

- 功能：服务商可选 Chat Completions 或 Responses 接口；既有档案保持 Chat Completions，OpenAI Luna 快速模板选 Responses。连接测试、轻任务、一次性 JSON 解析与 Agent 工具会话都随档案选择接口。
- 配置：新增 `AGENT_WIRE_API`、可选 `LIGHT_WIRE_API`；Responses 以无状态 `store: false` 发送，密钥仍只存本机 `.env`。

## 0.7.1-alpha.1

- 修复：模型网关返回 HTML 页面时，连接测试、轻任务和 Agent 会话明确提示 Base URL 与 Chat Completions 接口类型错误；无正文耗尽回合步数不再假装成功并要求用户反复「继续」。

## 0.7.0-alpha.1

- 功能：模型与端点快速模板新增 OpenAI GPT-5.6 Luna；连接测试、轻任务、一次性 JSON 解析与 Agent 会话使用与官方 Chat Completions 兼容的参数。
- 修复：连接测试按端点族发送参数，避免将第三方网关的思考扩展字段发送给 OpenAI 官方端点。

## 0.6.0-alpha.1

- 功能：发送中心持续显示上次中断批次的可恢复组数和收件人数；恢复操作只作用于该批次。

## 0.5.7-alpha.1

- 安全修复：中断的发送批次在应用启动后等待用户确认，不再自动外发；确认恢复仅处理原批次。
- 安全修复：邮件内联图片不再读取 `file:` 或本地绝对路径；直接粘贴图片仍会转换为 CID 内联附件。
