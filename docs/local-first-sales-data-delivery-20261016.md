# 销售端本地优先与中心被动同步

## 交付范围

本节点固定销售端的数据边界，并收敛客户页的用户界面。没有新增数据库、IPC、HTTP 路由、依赖或配置键。

## 数据边界

| 数据 | 主写入位置 | 中心不可用时 |
| --- | --- | --- |
| 联系人补充资料、个人备注、跟进记录 | 销售端本地 SQLite | 可继续查看和保存，联网后由 outbox 上传 |
| 邮件草稿、发送队列、本地邮件缓存 | 销售端本地 SQLite | 可继续使用本地功能，联网后补传记录 |
| 账号邮箱、密码、角色、权限 | 中心数据库 | 只读缓存，不允许离线修改 |
| 线索归属、分配、共享、撤权、全局客户状态 | 中心数据库 | 只读缓存，不允许离线修改 |
| 邮箱密码、OAuth 凭据 | 本机加密存储 | 不上传中心；换设备需重新授权邮箱 |

本地变化通过现有 outbox 主动上传。中心接收时继续校验当前权限、联系人版本、撤权状态和幂等键；失败记录留在后台队列中等待重试。

## 用户界面

客户列表、详情和跟进页已移除同步状态面板、同步标签以及“待同步/同步失败”等技术性提示。保存成功只显示“已保存”；当前操作真实失败时才显示错误。同步、冲突、重试和撤权状态仍保留在后台服务和 IPC 中，供恢复链路使用。

## 验收边界

- 离线可继续使用已缓存联系人、邮件缓存、草稿、发送队列和本地跟进。
- 中心账号权限、分配和全局状态不在离线时开放修改。
- 更换电脑可以恢复已同步的中心资料，但必须重新授权邮箱凭据。
- 本节点未改变收件箱、发信、AI 和中心同步协议的既有接口。
