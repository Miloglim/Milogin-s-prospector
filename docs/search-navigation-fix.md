# 全局搜索入口与定位修复 — 2026-10-10（待发布）

原因：全局搜索入口单独占据侧栏导航上方空间；收件箱、联系人和 CRM 的深链解析只在挂载时执行，同页点击无响应。筛选变化还会清掉深链选中的邮件，而超出列表分类上限的邮件无法在详情中找到。

结果：入口移至侧栏底部设置按钮旁，复用同款图标按钮；邮件命中后恢复全部分类、清除搜索/发件人限制、回到平铺视图，额外取得目标行并滚动定位、显示正文。同页联系人与 CRM 深链也响应新参数。目标已删除时提示；快速切换的迟到正文不覆盖当前邮件。

副作用：邮件深链会重置当前收件箱筛选；超出常规列表上限的目标额外增加一行，但不解除数量限制。底部导航项收起时隐藏版本文字，保证设置和搜索都不被挤出侧栏。首次目标正文加载仍使用现有正文获取流程，必要时会从邮箱下载。

检查点：`D:/Agent Basement/checkpoints/prospector-search-navigation-20261010/`，包含改动前源码/文档、浏览器隔离验证脚本、截图和日志。真实邮件与正式数据库未参与这次交互测试。

验证：Edge 无头浏览器加载真实 Sidebar、GlobalSearch、InboxList、CustomersPage/ContactList/CrmPipeline，使用应用生成的 CSS 与隔离 IPC 数据，核对底部相邻位置及 64px 收起栏可见性、同页带筛选跳转、列表滚动、超上限邮件、正文请求乱序、已删除邮件提示、跨页进入及连续联系人/CRM 深链。真实 Electron SQLite 隔离测试另核对常规列表上限、附带目标行、非法 ID 与缺失 ID。

这是本地修复，尚未发布新 Release；已发布的 v0.9.1-alpha.1 安装包不包含本次改动。

## 搜索结果布局

原因：摘要保留原邮件换行，导致结果行大片空白；蓝色链接标题和浏览器默认黄色高亮与应用主题不一致。

调整：摘要合并空白、最多显示两行；标题单行省略，整行可点击；分类仅显示有结果的组，使用主题文字色、柔和高亮及悬停/键盘焦点反馈，结果区域独立滚动。

副作用：完整摘要需点击进入详情阅读，邮件原文不变。无新增依赖。

布局节点改动前检查点：`D:/Agent Basement/checkpoints/prospector-search-results-layout-20261010/`。浏览器用多段换行、超长摘要验证行高、两行截断、空白合并及详情跳转；同时完成连续联系人/CRM 深链验证。类型检查、生产构建、架构边界检查通过。
