# 旧 SQLite 联系人迁移测试转换层（2026-10-16）

本节点只完成“旧联系人 → 中心个人导入请求”的纯转换，不执行数据库读取、网络请求或中心写入。

转换规则：

- 固定使用 `kind: personal`，避免把销售自有联系人误写成管理员线索。
- 邮箱标准化为去空格并转小写。
- 公司编号存在时使用 `legacy-company-{companyId}` 作为客户幂等键；没有公司编号时退回本地联系人编号。
- 保留姓名、职位、电话、LinkedIn、国家、语言、客户类型、阶段、状态、标签等已有字段。
- 缺少有效邮箱或公司名的记录直接跳过，不生成无法入库的请求。
- 原始本地 ID 只放入 `rawRow`，供迁移回执核对，不作为中心业务字段展示。

本节点没有接入运行时同步，也没有向 PostgreSQL 写入测试或真实联系人。下一节点才会在确认权限、分批大小、失败重试和回执回填后接入现有 `/api/crm/imports`。

验证：`legacy-contact-sync.test.ts` 3/3；未进行正式中心写入。
