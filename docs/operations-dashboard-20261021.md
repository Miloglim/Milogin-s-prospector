# 管理中心系统运行页

版本：`0.55.0-alpha.1`，工作区未发布。

## 范围

管理中心新增“系统运行”入口，只读展示中心版本、进程运行时长、Navigator 健康、中心 PostgreSQL 大小、服务器磁盘使用率和自动备份未接入状态。接口为 `GET /admin-api/operations`，沿用现有管理会话、CSRF/同源边界和 summary 管理员/审计员读取权限。

Navigator 离线时只把该项标为异常，中心数据库、磁盘和备份项仍返回。刷新失败时前端保留上次快照。没有新增写接口、数据库迁移、依赖、Shell、Docker Socket 或发布按钮。

## 验证

- 管理中心管理端类型构建、服务端类型构建和 `npm run check` 通过。
- 管理中心 API、HTTP 编排、系统运行渲染和现有看板权限共 18 项定向测试通过。
- 本机隔离中心启动后，管理员接口返回中心、PostgreSQL、磁盘、Navigator 与备份状态；普通销售访问返回 403。
- 真实 Edge 验证系统运行页数据、刷新和权限菜单显示；无权限运营账号不显示该入口。测试期间的临时管理员授权已恢复，测试会话已撤销。
- 全量 `npm run typecheck` 当前被工作区另一组未完成收件箱改动阻塞，错误不涉及本节点文件。

## 回退

代码回退到 `0.54.0-alpha.1` 即移除页面和只读接口；无数据库迁移或持久配置变更，不需要恢复数据库。
