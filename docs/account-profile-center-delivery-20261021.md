# 中心账号资料与成长统一交付

日期：2026-10-21
版本：Prospector `0.54.0-alpha.1`，Navigator `6.50.0`

## 已实现

- 中心 `GET /api/account/profile` 按有效 API 会话返回共享显示名、头像 ID、简介和成长摘要。
- 中心新增 `POST /api/account/profile` 和 `POST /api/account/growth`。前者只允许本人更新显示名/头像/简介，后者按会话用户、产品准入、规则版本、每日上限和稳定主题键幂等记账。
- Prospector 新增 `online:account-profile` IPC、主进程服务和中心适配器；账号资料页保留现有布局，读取中心昵称、预设头像、等级与经验进度。
- 成长等级和本级进度由中心总经验按既有 50 级循环规则派生，缺失数据仍显示未知。
- Navigator 预设头像以白名单 ID 共享，Prospector 打包同套 61 个 PNG，不复制 Navigator 业务 API 或会话。
- `scripts/migrate-navigator-account-profile.mjs` 默认 dry-run，显式 `--apply` 才写中心；包含账号解析、冲突预检、稳定事件 UUID、管理审计、幂等写入，以及事务内经验事件和成长投影双重核对。
- Navigator 资料保存先更新中心共享资料，再保存航线、群聊、默认页签和查价开关；本地显示名仅保留业务检索镜像。
- Navigator 业务经验写入 `account_growth_sync_outbox`，登录、账号页读取和新经验产生时补传中心；中心离线不丢本地事件。
