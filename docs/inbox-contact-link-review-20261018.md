# 收件箱与联系人关联核对（2026-10-18）

## 结论

现有收件箱链路已经与统一客户页的联系人身份对齐，本节点未发现需要改动的生产代码，也没有新增页面、IPC、HTTP、数据库字段、依赖或配置。

## 已核对链路

1. 本地收件箱以账号隔离读取，邮件按标准化邮箱匹配联系人；已有联系人关联不会被新匹配抢走。
2. 收件箱在联系人建立后可以补挂历史邮件；重复执行不会重复生成关联、跟进活动或退信关系。
3. 联系人详情“往来记录”同时展示邮件事实和独立跟进记录，邮件活动不会重复计入。
4. 本地发送、回复、收件、退信和自动回复生成结构化事件；中心接口按事件键幂等接收，中心不接管本地发信。
5. 中心断线时事件留在本地待同步队列；恢复后继续提交，账号切换、撤权和联系人失效不会把旧账号数据写入当前账号。
6. 没有中心映射的旧联系人不会被猜测关联，也不会把本地编号当作中心编号。
