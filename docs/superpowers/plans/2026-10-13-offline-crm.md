# 客户中心离线实施计划

用户已批准本地优先、联网同步，并取消多表导入。单表导入保留。

1. 先用测试证明本地客户读取、创建、编辑、跟进、单表导入、账号隔离和幂等重放。
2. core 定义同步状态、待同步操作和本地投影；services 通过存储/网络端口处理读写与同步；SQLite adapter 按中心地址和账号分库存储，事务持久化。
3. 在线适配器接入本地服务；身份失效禁止读写。登录恢复和轮询触发同步，授权变化清理旧投影并冻结未完成操作。完整分页拉取可访问客户，联系人和动态随客户详情缓存；缓存有覆盖状态和时间。
4. 创建/编辑/跟进/导入先本地事务，联网后自动提交。依赖操作在前序成功后映射中心 ID 和联系人 ID；首次发出后固定请求，丢响应使用原幂等键重放。冲突不覆盖，用户可保留中心或核对后重试本地。
5. 分配、领取、发布以及任务/商机修改仍在线执行；任务/商机读取缓存。旧 contacts 和邮件链路保留既有账号绑定，不擅自把无归属旧库分配给登录者。
6. 移除多表 UI 入口及其 IPC；旧服务端导入历史兼容保留。客户页展示离线、待同步、失败与冲突处理。
7. 运行行为测试、类型检查、构建、架构检查、隔离 Electron/SQLite 断网重启冒烟；同步源文档和知识库，记录实际覆盖范围。

验收：已有有效离线授权的账号断网重启能进入客户页；本地修改重启不丢；恢复连接自动同步不重复；并发中心修改报冲突；账号切换不串数据；无多表导入入口。
