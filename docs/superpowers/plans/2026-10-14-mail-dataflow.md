# 中心与本地邮件数据流接入

用户批准：先中心/本地库及接口适配，复杂版本、冲突、删除、撤权、重试管理后置。前端布局固定。用subagent-driven-development与测试先行执行，本工作区有既有未提交变更，不重置、不推送、不安装依赖。

## 本轮范围与约束

中心授权联系人同步已有账号隔离crm-offline.db结构化投影；自有及已接受分配共用。旧contacts保留历史，不将中心数字ID写成本地FK。旧收件/分类/正文/附件仍沿用；匹配通过明确数据端口，互动在本地保存来源关联并回传中心，中心详情展示真实邮件摘要。当前中心联系人在线字段修改成功后更新本地投影。正文原文上传与附件同步不在本轮，邮件同步仅必要元数据/摘要。不新建分配数据库，不写邮箱密码或外发邮件。

最低正确性仍需：中心身份校验/已有授权，显式中心引用、单事件去重，本地待同步事件保留失败不伪报成功。暂不新增通用冲突UI、离线字段修改、自动退避、删除/转派流程；不得以“后置”删除已有权限/版本检查。

## 任务

- [x] 契约先行：中心mail-event输入、回执、路径与详情邮件摘要类型；不新增重复登录/消息/手动测试IPC。
- [x] 中心接口：复用联系人授权查询、事务/outbox；新增邮件来源事件表，独立事件同步/去重与联系人触达更新、活动摘要；详情返回邮件事件。
- [x] 本地投影：已有缓存库结构化中心联系人、关联邮件与待同步事件；按账号/中心隔离；同一ID更新和邮箱匹配，不复制到旧contacts。
- [x] 旧收件箱适配：主流程及历史补挂触发本地中心关联，旧本地历史链保留；中心关联不进入旧数字ID写/删除/营销信号路径。
- [x] 主程序接线：身份有效时刷新授权联系人到投影，邮件落地收集事件并上传；成功联系人写和邮件回执刷新投影；账户切换防迟到响应。原详情沿原布局展示中心邮件事件。
- [x] 单元/真实PG回滚/真实Electron及SQLite数据流验证；不得保留临时账号、业务测试数据或真实外发。
- [x] 源码/中心dump checkpoint，文档版本知识库写回，受控中心重载。用户当前窗口不强制终止。
