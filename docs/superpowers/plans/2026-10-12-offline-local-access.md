# 离线本地工作区实施计划

用户已接受有限离线方案并要求服务器下线时用户仍可使用基础功能。沿用身份与个人目录，不新增离线CRM数据库或写回队列。按writing-plans/subagent-driven-development实施，先checkpoint；本机合成账号和隔离目录测试，无邮件外发。

原因：中心暂时故障被等同登录失败，使本地功能一起停摆。
提升：当前会话不中断；记住登录的账号在72小时有效离线授权内可重开本地工作区。网络与DB故障不清凭据，明确撤销/禁用仍清理。
副作用：离线撤权延迟最多授权剩余期限；客户端必须显示离线，禁止中心写入；首次/已退出/过期无有效授权仍在线登录。未记住登录只保留本次进程，不跨重启恢复。

契约：OfflineAccessGrant签名身份快照＋发行中心＋prospector-local audience＋到期时间，中心Ed25519签发，本机DPAPI保护存储，主进程验证。DesktopLoginResponse增加可选offlineAccess，OnlineSessionSnapshot增加可选connection/offlineExpiresAt；不新增IPC/API/依赖/数据库迁移。签名是应用内部授权签名，无代码签名证书费用。

- [x] 中心离线授权：core契约先行，密码强制修改身份不签发；adapter保存签名私钥于既有受控测试runtime，service注入纯端口，登录/续期返回。旧测试中心可不提供，不自动信任未签名缓存。
- [x] 桌面签名验证、有限离线恢复：保护原refresh、身份相同/issuer/audience/期限/签名校验，故障时本地身份保留；在线请求明确返回不可用，重连重新核验；logout/强制改密/撤销清理。时钟倒退失败关闭，不无限延长。
- [x] 本地守卫：个人目录隔离保持；已初始化不因离线重启；离线只允许本地查看/草稿/素材/设置，阻止新外发、联网AI、同步及共享CRM操作。不强行停止正在执行的旧外部任务，但离线开机不恢复发送批次，后续不自动补发。
- [x] 前端：离线状态仍进入壳，简短状态提示；中心页面禁用操作，不伪造实时数据，首次离线启动落到本地收件箱。未授权过不自动创建身份。
- [x] 验证：伪造/过期/错账号/错issuer/回拨/退出/失权/并发续期单测，PG/HTTP签发和重启，实际Electron在线登录→断网/DB故障→本地设置素材/邮件→中心写拒绝→重开离线→恢复→撤权；接口数量仍22，三端构建/架构/受影响测试。
- [x] 版本、契约、架构、陷阱、知识库写回和checkpoint证据，明确局域网/公网及持续Worker未完成。
