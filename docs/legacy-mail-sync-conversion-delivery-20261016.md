# 旧本地邮件事件转换层（2026-10-16）

本节点建立旧 SQLite 邮件记录到中心邮件事件契约的纯转换层，暂未接入运行时队列。

- `interactions` 和 `inbox_messages` 使用来源前缀加本地 ID 生成稳定 `eventKey`，避免两个旧表的编号冲突。
- 只传中心需要的联系人 ID、客户 ID、收发方向、发生时间、主题和摘要。
- 不传邮件原文正文、附件、账号密码或本地数据库编号作为中心业务编号。
- 邮箱统一去空格并转小写；主题限制 998 字符，摘要限制 2000 字符，与中心契约一致。
- 后续运行时接入必须先通过 `crm_legacy_contact_map` 找到唯一中心联系人，未映射记录不得上传。
