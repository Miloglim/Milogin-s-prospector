# B3 跟进任务与到期提醒方案

2026-10-13；已批准并在工作区实施，未发布。

原因：当前可登记跟进，但缺少下一次联系时间、待办和完成反馈，链路停在记录历史。

改动：客户详情沿用原布局新增下一次跟进时间与简短任务；中心存任务负责人、到期、状态、关联客户和完成反馈；中心到期生成持久通知，客户端在线接收、断线补收。管理员查看其导入线索的待办与进度，用户只处理自身任务，超级管理员按既有全量范围查看。不引入自动邮件外发或大模型自动改状态。

提升：跟进后能约定下一步，到期能提醒，完成或延期有记录，管理员可区分未跟进和任务未完成。

副作用：新增任务表和接口，需要处理重复提醒、重新分配、过期/延期与账号停用；提醒依赖中心运行，断线后补收，不能保证离线时即时通知。

验收：创建任务→到期通知→完成反馈；延期后旧提醒不再有效；多端同步且不重复；转交客户后任务归属规则一致；无权限者不可查看/操作。每步checkpoint，隔离数据测试并回收。后端PG回滚、HTTP/worker和桌面渲染定向测试已通过；真实Electron窗口任务点击与真实Excel导入仍待本地手工验收。
