统一客户入口已经按同一页面完成运行时验证：在线时读取中心联系人投影，中心不可用时读取当前账号的本地联系人镜像；恢复连接后回放本地待同步命令。没有增加新的客户页面、数据库、公共 IPC 或 HTTP 接口。

## 验证范围

- 在线启动后通过真实 Electron IPC、preload、renderer 和 native SQLite 加载统一客户页。

- 中心恢复后执行同步，离线创建、字段修改和跟进按依赖顺序回放，中心端不重复生成记录。
- 中心版本发生变化时保留本地跟进记录并报告冲突，不静默覆盖。
- 切换到第二个身份后使用独立本地 SQLite，不能读取上一个身份的客户和详情。
